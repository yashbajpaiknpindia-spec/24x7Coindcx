IMPORTANT LIMITATIONS

Before deployment

  • Run the app and worker in the same Render region as PostgreSQL; the Blueprint provisions a database and two services.
  • Render Blueprint plans in the supplied file are paid starter/basic plans; review current prices before pressing Apply.
  • Historical backtest snapshots preserve previous outputs but do not make those results independently verified.
  • Manual live tickets and a daily automated live rebalance are implemented behind separate environment gates and typed UI arming. Both deployment gates default to false; do not enable automation until paper, API permissions, reconciliation, and caps are verified.
  • Spot order market codes and futures instrument eligibility are mapped from current CoinDCX metadata rather than guessed.
