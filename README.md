# Binance Copy Intelligence

The fresh application lives in `binance-copy-intelligence/`. Its Render service is configured to build from that directory only, so the legacy CoinDCX Strategy Terminal is not part of the active application UI.

## Active application

- App: https://binance-copy-intelligence-v2.onrender.com
- Source directory: `binance-copy-intelligence/`
- Legacy root project: preserved under `archive/legacy-coindcx-terminal/`

The former root-level CoinDCX Strategy Terminal files were moved intact into the archive path to keep the active project separate while preserving the source history. Do not deploy the archived project as the Binance app.
